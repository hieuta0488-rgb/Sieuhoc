# Siêu Học

Phần mềm học tập chạy **offline** trên Windows:

- 🏫 **Tiếng Anh lớp 1 → 12**: 154 bài học theo Chương trình GDPT 2018 (nội dung tự soạn, không sao chép sách giáo khoa)
- 🏆 **815 câu luyện đề** chia cấp độ: Cơ bản · Nâng cao · Olympic/IOE · HSG cấp tỉnh · HSG quốc gia — có lời giải từng bước và mẹo
- 🎯 **TOEIC**: 4.547 từ vựng (phiên âm, ví dụ, phát âm), 30 bài ngữ pháp, luyện 7 phần thi, thi thử thang 990
- 🔁 Ôn tập ngắt quãng, lộ trình học theo ngày, theo dõi tiến độ

## Tải về

Vào mục **[Releases](../../releases/latest)** và tải:

| File | Dùng khi |
|---|---|
| `SieuHoc_Setup_x.y.z.exe` | Cài cho từng máy, không cần quyền quản trị |
| `SieuHoc_x.y.z.msi` | Cài hàng loạt / cho mọi tài khoản trên máy (cần quyền quản trị) |
| `SieuHoc_offline.html` | Không cần cài: bấm đúp mở bằng trình duyệt |

Nếu Windows báo "Windows protected your PC": bấm **More info → Run anyway**.
